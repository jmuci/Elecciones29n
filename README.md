# Elecciones29n

Comparador de las propuestas de los principales partidos para las **elecciones generales del 29 de noviembre de 2026**, tema a tema y con enlace a la fuente oficial de cada propuesta.

Proyecto personal de un ciudadano particular, sin afiliación a ningún partido.

- **Plan y roadmap:** [`PLAN.md`](PLAN.md)
- **Reglas de neutralidad y cómo contribuir:** [`CONTRIBUTING.md`](CONTRIBUTING.md)
- **¿Has visto un error?** Abre un [issue](../../issues) indicando la propuesta, el partido y la fuente.

> Los resúmenes son propios. La fuente oficial de cada partido siempre prevalece.
